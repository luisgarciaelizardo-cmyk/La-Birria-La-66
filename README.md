# Birria La 66

Sitio web de **Birria La 66 · Birria de res**.

Es un sitio estático: abre `index.html` en el navegador o publícalo con GitHub Pages
(Settings → Pages → Branch: `main` / root).

- `index.html` — página (menú, galería, ubicación y redes sociales)
- `styles.css` — estilos; la paleta sale del logo y del menú
- `script.js` — menú móvil y visor de imágenes
- `img/` — logo, menú original y fotos
